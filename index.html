Homelab

My homelab is a custom-built server environment that I use to experiment with Linux administration, virtualization, networking, cybersecurity, and self-hosting.

The server runs Proxmox VE, which allows me to create and manage virtual machines and LXC containers for different applications and services. It has become an ongoing project where I can experiment with new technologies while hosting services that are actively used by friends and family.

Services

  • Frigate - An AI-powered object detection system for monitoring and analyzing camera footage.
  • Immich - A self-hosted photo and video management platform used to organize my family's digital photo library.
  • PufferPanel - A game server management utility used to deploy and manage multiplayer servers such as Minecraft and Terraria.
  • Tailscale - A mesh VPN that allows me to securely access my homelab services remotely.
  • AdGuard - A DNS filtering service that blocks advertisements and unwanted domains across my network.
  • DuckDNS - A dynamic DNS service that keeps my homelab reachable when my public IP address changes.
